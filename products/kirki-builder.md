# Kirki Builder

> Status: DRAFT — written from public information. Needs review by the Kirki product/brand owner.

## What it is
Kirki is a freeform visual website builder for WordPress (by Themeum, an Ollyo company)
and an advanced theme customizer. It has an infinite freeform canvas without rigid grids,
responsive controls, dynamic content (collections & templates), interactions/animation
timeline and a popup builder (Pro). It works with any theme. Free core plus Kirki Pro.

## Who the users are
- **Primary:** Web designers and creative freelancers who want design freedom inside WordPress (often coming from Figma or Webflow-style tools).
- **Secondary:** Agencies building client sites; theme developers using the Kirki customizer framework; ambitious DIY site owners.
- **Technical level:** No-code (the official tagline is "No-Code Site Builder"), but design-savvy. They care about craft, not code.

## What they care about
- Creative freedom: pixel-level control, no layout restrictions.
- Modern design capabilities: interactions, animations, dynamic content.
- Speed of building and clean output.
- Staying in WordPress without compromising on design.

## Key messages / value props
- Design freely on WordPress: no grids, no limits.
- Visual building with professional-grade control.
- Interactions, animation and dynamic content built in.

## Tone & voice
- **Is:** Confident, modern, creative, design-forward. Speaks designer language (canvas, interactions, freedom).
- **Is not:** Code-heavy or developer-jargon, cluttered, "cheap page builder" or template-mill feel.

## Common mistakes to flag
- The design looks dated or template-like. That undermines a design-tool brand. **Hold Aesthetics to a higher bar.**
- Generic "page builder" messaging that doesn't communicate freeform design.
- Cluttered feature lists instead of showing the result.
- Confusing Kirki Builder with Kirki eCommerce messaging.
