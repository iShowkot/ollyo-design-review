# Hard fails

Any one of these = **REJECTED**, no matter how high the scores are.
Always still score the design fully so the designer gets complete feedback.

| # | Hard fail | How to check |
|---|---|---|
| H1 | **Unreadable text** | Key text (headline, CTA, key message) has very low contrast (roughly < 3:1) or is too small to read at actual display size for the channel. |
| H2 | **Wrong brand** | Wrong product logo, another Ollyo product's colors/identity, or an outdated logo. |
| H3 | **Content outside safe zone** | Key content (headline, logo, CTA, faces) cut off or at risk of being cropped for the stated channel/size (e.g. blog banner cropped on mobile, social platform UI overlays). |
| H4 | **Spelling / grammar error in headline or CTA** | Read every word character by character. Product names must be spelled exactly as in the product file (e.g. "Tutor LMS", not "TutorLMS"). |
| H5 | **Wrong or misleading claim** | Prices, discounts, dates, version numbers or feature names that contradict the brief or product file. If unsure, flag it as a question rather than a hard fail. |

When reporting a hard fail, say exactly where it is and how to fix it.

_Teams: add new hard fails here as you learn them. Keep each one objective and checkable._
