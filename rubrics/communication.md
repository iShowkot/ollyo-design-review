# Score 1 — Communication (out of 10)

**Question:** Does this design communicate the right message, to the right users of
this product, in a way that achieves the stated goal?

Pass mark: **8.0**

| # | Sub-criterion | Weight |
|---|---|---|
| C1 | Message clarity | 3.0 |
| C2 | Audience fit | 2.0 |
| C3 | Goal alignment | 2.0 |
| C4 | Brand recognition | 1.5 |
| C5 | CTA / next step | 1.5 |
| | **Total** | **10.0** |

> **No-CTA assets:** If the asset type legitimately has no CTA (e.g. most blog banners,

> Score C1 out of 4.5 instead (add C5's 1.5 to C1). State this in the review.

## C1 — Message clarity (3.0)
Can a viewer understand the main message within ~3 seconds at actual display size?

| Score | Anchor |
|---|---|
| 3.0 | One unmistakable message. Headline says it in plain words. Nothing competes. |
| 2.0–2.5 | Message is clear but takes a second look; supporting text or visuals compete slightly. |
| 1.0–1.5 | Message is there but buried, vague, or split between two ideas. |
| 0–0.5 | Viewer can't tell what this is about. |

Check: headline wording (benefit vs. jargon), number of competing messages, word count,
whether visuals reinforce or distract from the message.

## C2 — Audience fit (2.0)
Does the tone, imagery, language and level of complexity suit this product's users
(see product file)?

| Score | Anchor |
|---|---|
| 2.0 | Feels made for these users. They'd recognize themselves and their needs in it. |
| 1.5 | Generally appropriate; a few elements feel generic or slightly off-tone. |
| 1.0 | Generic — could be for any SaaS/WordPress product. |
| 0–0.5 | Wrong audience (e.g. developer jargon for non-technical educators). |

## C3 — Goal alignment (2.0)
Does the design actually do the job stated in the brief?

| Score | Anchor |
|---|---|
| 2.0 | Every element serves the goal (announce → news is obvious; sell → offer is obvious). |
| 1.5 | Serves the goal, but some space is spent on things that don't help it. |
| 1.0 | Partially serves the goal; the main goal element is weak or secondary. |
| 0–0.5 | Works against or ignores the goal. |

## C4 — Brand recognition (1.5)
Is it clearly *this* product (logo, colors, visual language from the product file)?

| Score | Anchor |
|---|---|
| 1.5 | Instantly recognizable as the product; consistent with its visual identity. |
| 1.0 | Logo present but the overall look could belong to another brand. |
| 0.5 | Brand weak or inconsistent (off-palette, off-style). |
| 0 | Not identifiable. (Wrong logo/brand is a hard fail.) |

## C5 — CTA / next step (1.5)
Is it obvious what the viewer should do next?

| Score | Anchor |
|---|---|
| 1.5 | Clear, specific, action-oriented CTA; visually prominent; matches goal. |
| 1.0 | CTA present but generic ("Learn more") or under-emphasized. |
| 0.5 | CTA hard to find or mismatched with goal. |
| 0 | Missing when the goal needs one. |
